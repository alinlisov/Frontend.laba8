## Запуск у PyCharm

**Спосіб 1 - найпростіший:**

1. Розпакувати папку проєкту.
2. У PyCharm вибрати **File - Open...** і вказати `Frontend_Lab8_Variant14`.
3. Відкрити `index.html`.
4. Натиснути правою кнопкою на файлі і вибрати **Open in Browser**, або відкрити цей HTML-файл у браузері через Провідник Windows.

**Спосіб 2 - через локальний сервер:**

Відкрити термінал PyCharm у корені проєкту та виконати:

```powershell
python -m http.server 8000
```

Якщо команда `python` не працює у Windows, спробувати `py -m http.server 8000`. Відкрити `http://localhost:8000/`.

Для HTML/CSS-проєкту **не потрібні** `pip install`, `npm install`, `npm run dev`, Vite або Node.js.
